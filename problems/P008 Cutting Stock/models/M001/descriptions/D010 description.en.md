# Cutting aluminum profiles for windows

A fabrication workshop produces **aluminum profiles for window frames**. The workshop receives standard extrusion bars
from the supplier and must cut them into shorter segments required for customer orders.

Each supplier bar has a fixed length denoted by **L**. Customer orders specify several types of frame segments. Segment
type *i* requires pieces of length **l_i**, and the total number of pieces demanded for this type is **d_i**.

Because the bars are expensive, the workshop wants to plan the cuts carefully. Every bar that is cut generates some
leftover material (offcut), which may be too short for reuse. Let the unused portion of a bar be interpreted as **waste**.

To eliminate redundant configurations and speed up the planning process, the workshop considers all supplier bars to be
identical and ordered. If a bar is utilized, it must be selected before any subsequent bars in the sequence, ensuring that
all used bars are grouped at the beginning of the schedule.

The planning task is to determine how to cut the supplier bars so that:

* The required number of segments of each type *i* is satisfied.
* The total number of bars used is minimized.

In practical terms, the workshop seeks a cutting schedule that fulfills all window frame orders while using as little
aluminum as possible, thereby reducing cost and scrap.
