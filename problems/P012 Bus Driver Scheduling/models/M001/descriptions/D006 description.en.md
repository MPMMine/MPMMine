# Transport Crew Assignment

Transport crew assignment can be approached as a set partitioning challenge. Each scenario presents a defined collection
of activities (operations) to complete and a comprehensive set of potential work schedules, where each schedule
encompasses a selection of activities and carries a particular expense. The objective is to choose a subset of these
schedules such that every activity is included exactly once: this forms what is termed a partition. Moreover, the
primary goal is to minimize the quantity of schedules used in the final partition, with the overall expense being a
secondary consideration. For simplicity, all schedules have the same cost, meaning the main aim is to reduce the total
number of schedules.
