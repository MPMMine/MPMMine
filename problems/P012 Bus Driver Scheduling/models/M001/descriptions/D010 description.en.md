# Shift Allocation Problem

This problem involves scheduling bus drivers to complete a series of tasks. It's modeled as a set partitioning challenge
where we aim to create a feasible arrangement of shifts to cover all tasks exactly once. The objective is to minimize
the total number of shifts used in the solution. Each shift offers coverage for a specific subset of tasks, and we must
select a unique combination of shifts to ensure all tasks are fulfilled. Notably, the cost associated with each shift is
assumed to be identical, so reducing the total number of shifts becomes the primary goal. The problem originates from a
benchmark set of scheduling instances.
