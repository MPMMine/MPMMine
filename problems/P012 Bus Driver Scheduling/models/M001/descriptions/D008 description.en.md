# Driver Scheduling Problem

This problem involves creating a schedule for bus drivers, presented as a set partitioning challenge. We are given a
collection of distinct tasks (representing work assignments) and a range of available shifts. The goal is to devise a
schedule where each task is covered by precisely one shift. Our objective is to determine the smallest possible number
of shifts required to complete all tasks, prioritizing minimizing the number of shifts utilized. We are assuming that
all shifts have the same cost.
