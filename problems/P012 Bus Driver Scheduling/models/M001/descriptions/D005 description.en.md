# Work Assignment Problem

This problem can be modeled as a set partitioning task. Each instance includes a given set of activities to be covered
and a large collection of potential assignments, where each assignment covers a subset of the activities. The goal is to
select a subset of these assignments that covers every activity exactly once, forming a partition. The primary aim is to
minimize the number of assignments used, while the total cost is considered less important. To simplify, all assignments
have the same cost, meaning the objective is purely to minimize the number of assignments.
