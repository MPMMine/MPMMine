# Schur's theorem

The Schur number $S(n)$ is the largest integer $k$ such that the set of integers $\{1, 2, \dots, k\}$ can be partitioned
into $n$ sum-free sets. A set $A$ is sum-free if for any $x, y \in A$ (where $x$ and $y$ can be the same), their
sum $x + y$ is not in $A$. Find $S(n)$ for the given $n$.

To optimize performance, a **value precedence constraint** is applied. This enforces that a set label $c + 1$ can only be used if label $c$ has already been assigned to a smaller integer, ensuring that the partitions are filled in a strict, sequential order.
