# Items and containers

The task involves distributing a set of labeled items into a collection of containers such that for any group of three
items where the sum of the labels of two items equals the label of the third, not all three items are placed in the same
container.

The goal is to determine if it's possible to arrange the items into the given number of containers without violating the
specified condition. The solution requires ensuring that for every possible combination of items where one item's label
is the sum of the other two, the three items are not all located in the same container. This constraint must be
satisfied for all such combinations within the set of items.
