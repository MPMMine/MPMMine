# Items assignment

The task is to assign $N$ distinct items numbered from $1$ to $N$ into $B$ containers such that for every triple of
items $(x,y,z)$ with $x+y=z$, the three items are not all placed in the same container. Each item $i$ must receive a
container label drawn from the set $\{1,\dots, B\}$.
