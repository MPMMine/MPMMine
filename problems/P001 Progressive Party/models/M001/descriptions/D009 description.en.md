# Yacht Club Party Scheduling Challenge

The objective is to plan a series of gatherings at a maritime club, utilizing a selection of boats as hosts. Guest
vessels will then visit these host boats for a series of shorter intervals, typically thirty minutes in duration. Each
host boat must maintain a certain number of personnel on board, while guest vessels bring their own crews. The capacity
of each boat is limited, and the total number of people present on any given vessel—including both host and guest
crews—cannot exceed this capacity. Furthermore, guest vessels are restricted from repeatedly visiting the same host and
host and guest crews cannot interact simultaneously. The event organizer’s primary concern is to determine the minimum
number of boats that need to function as hosts to accommodate all the planned activities.
