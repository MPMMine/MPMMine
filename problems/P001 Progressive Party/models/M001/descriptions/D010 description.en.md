# Yacht Club Party Scheduling Challenge

The task involves arranging a gathering at a nautical club. Several boats will serve as host vessels, and crews from
other boats will successively visit these hosts for shorter intervals, typically thirty minutes long. Each host boat has
a maximum passenger capacity, and the combined number of people – including the host crew and visiting crews – cannot
exceed this limit for any given boat. Furthermore, a particular boat can only accommodate a specific number of people,
and guest crews cannot repeatedly interact with the same host boat or host crew. The organizer’s objective is to
determine the smallest number of host boats needed to manage this event.
