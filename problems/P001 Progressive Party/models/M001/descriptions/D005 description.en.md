# Host Boat Scheduling Problem

The objective is to schedule an event at a marina.

A selection of boats must be chosen as hosts, and the crews of the other boats must visit these hosts during multiple
consecutive half-hour intervals. The crew of a host boat stays on board to provide hospitality, while the crew of a
guest boat visits several hosts in sequence. Each boat has a maximum occupancy constraint, which limits the total number
of people on board at any time, including both host and guest crews. The size of each crew varies. A guest boat cannot
revisit a host, and guest crews cannot encounter each other more than once. The challenge for the event coordinator is
to minimize the number of host boats.
