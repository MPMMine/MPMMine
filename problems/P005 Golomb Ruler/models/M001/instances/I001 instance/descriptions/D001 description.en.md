# Golomb ruler problem

A Golomb ruler may be defined as a set of 3 integers 0 = a_1 < a_2 < ... < a_3 such that the 3.0 differences a_j - a_i, 1 <= i < j <= 3 are distinct. Such a ruler is said to contain 3 marks and is of length a_3. The objective is to find optimal (minimum length) or near optimal rulers.
