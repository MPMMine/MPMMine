# Golomb ruler problem

A Golomb ruler may be defined as a set of 10 integers 0 = a_1 < a_2 < ... < a_10 such that the 45.0 differences a_j - a_i, 1 <= i < j <= 10 are distinct. Such a ruler is said to contain 10 marks and is of length a_10. The objective is to find optimal (minimum length) or near optimal rulers. Note that a symmetry can be removed by adding the constraint that the first difference is less than the last.
