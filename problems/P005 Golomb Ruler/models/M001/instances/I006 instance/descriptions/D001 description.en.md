# Golomb ruler problem

A Golomb ruler may be defined as a set of 8 integers 0 = a_1 < a_2 < ... < a_8 such that the 28.0 differences a_j - a_i, 1 <= i < j <= 8 are distinct. Such a ruler is said to contain 8 marks and is of length a_8. The objective is to find optimal (minimum length) or near optimal rulers.
