# Golomb ruler problem

A Golomb ruler may be defined as a set of 5 integers 0 = a_1 < a_2 < ... < a_5 such that the 10.0 differences a_j - a_i, 1 <= i < j <= 5 are distinct. Such a ruler is said to contain 5 marks and is of length a_5. The objective is to find optimal (minimum length) or near optimal rulers. Note that a symmetry can be removed by adding the constraint that the first difference is less than the last.
