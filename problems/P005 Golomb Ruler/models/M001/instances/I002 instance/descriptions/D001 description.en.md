# Golomb ruler problem

A Golomb ruler may be defined as a set of 4 integers 0 = a_1 < a_2 < ... < a_4 such that the 6.0 differences a_j - a_i, 1 <= i < j <= 4 are distinct. Such a ruler is said to contain 4 marks and is of length a_4. The objective is to find optimal (minimum length) or near optimal rulers.
