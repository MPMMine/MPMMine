# Golomb Ruler Specification

A collection of ordered abstract symbols drawn from a domain, beginning with a designated initial symbol and increasing
thereafter; the set generates pairwise differences that are all unique. The span label denotes the value attached to the
final symbol in the order

An extra rule may be imposed to break reflection symmetry by requiring that the first generated difference is smaller
than the last one

The construct does not need to represent every integer interval up to its span – if it does capture each possible
interval exactly once, it obtains classification as a perfect ruler
