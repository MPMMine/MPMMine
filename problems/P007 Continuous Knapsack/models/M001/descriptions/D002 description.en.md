# Optimal Loading in Flexible Containers

A container features adaptable sections that can be modified to create any number of compartments, with the total volume
remaining constant. Multiple items are available, each possessing distinct sizes and benefits. The challenge is to
identify the best fractional allocation of these items into the container to achieve the highest possible total benefit,
while ensuring the combined size of the loaded items does not surpass the container's maximum capacity. Furthermore, the
internal divisions can be freely adjusted to match the allocated volumes, provided the sum of all compartment volumes
equals the container's total volume.
