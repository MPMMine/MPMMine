# Langford's number

A Langford sequence of order k is a permutation of the multiset {1,1,2,2,…,k,k} such that for every integer n in the set, there are exactly n numbers positioned between the two occurrences of n. To ensure a unique solution, an additional constraint is imposed, requiring the first element of the sequence to be less than the last element.
