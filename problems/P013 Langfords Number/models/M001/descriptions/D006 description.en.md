# Langford Sequence

A Langford arrangement of order `k` is a specific ordering of the multiset containing two identical elements for each
integer from 1 to `k`, such that for each value `n`, the two occurrences of `n` are positioned with exactly `n` other
elements between them. Furthermore, to address symmetry, it is required that the first element is strictly less than the
last element. This ensures a unique representation while satisfying the core condition.
