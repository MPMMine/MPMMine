# Langford's Number Arrangement Challenge

Consider the problem of positioning two complete sets of integers from 1 to n into a single linear sequence. The
requirement is that for every integer i, the two instances of i must be exactly i+1 positions apart, ensuring there are
precisely i other numbers between them. A symmetry-breaking condition requires that the value at the first position is
less than the value at the last position, helping to reduce the search space.
