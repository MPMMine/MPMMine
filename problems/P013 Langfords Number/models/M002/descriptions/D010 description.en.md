# Arranging Numbers in Sequential Blocks

The task involves combining two sets of integers ranging from 1 to *k*, where *k* represents the size of each set into a
single sequence such that, following the initial appearance of a specific integer *i*, every subsequent occurrence of
*i* must appear at a distance of *i*+1 positions later within the sequence. A valid arrangement will maintain this
spacing between all identical numbers. First number must be smaller than the last one.
