# Langford's Number Arrangement Challenge

Langford's problem L(n) involves arranging two complete sets of integers from 1 to n into a sequence. The unique
requirement is that for each integer i, the second occurrence in the sequence must appear exactly i+1 positions after
its first occurrence. This arrangement must satisfy specific positional constraints. First number must be smaller than the last one.

This challenge requires finding an arrangement where the specified positional relationships hold for all numbers from 1
to n.
