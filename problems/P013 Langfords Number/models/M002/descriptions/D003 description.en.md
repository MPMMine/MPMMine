# Arranging Sequential Pairs

The goal of this problem, denoted as $P(n)$, is to organize two sequences of integers from 1 to $n$ in such a way that
the distance between consecutive occurrences of any integer $m$ is always separated by $m$ other integers. This means
for each number $i$, after its first appearance, every subsequent occurrence must be exactly $i+1$ positions later. The
challenge involves finding an arrangement where this rule holds true for all numbers with first number being smaller than the last one.
