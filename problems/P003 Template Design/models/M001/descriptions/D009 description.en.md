# Carton Design Optimization

This problem concerns a printing firm that creates various packaging products, including food cartons and magazine
inserts, using printed templates. These cartons differ in small aspects like text and color, but share the same basic
dimensions. The firm must determine the optimal number of distinct template designs to produce and the quantity of each
design to include on each template to minimize waste, considering the constraints of the printing machinery. The goal is
to determine the most efficient plan for utilizing mother sheets of board, which are etched with the design templates,
thereby reducing material waste.

To achieve this efficiency, the system needs to decide how many unique template designs to manufacture and the specific
number of copies of each design to include on each template. Employing more templates can reduce waste, but excessive
use will lead to unnecessary card usage. The problem is to establish a template production strategy that minimizes
waste, exploring options from one template to multiple templates to find the ideal balance.
