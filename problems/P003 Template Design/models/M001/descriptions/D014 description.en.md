# Template Design Issue

The task originates in a colour‑printing operation that must cut cardboard sheets into many identical‑shaped cartons.
Each carton design belongs to a line of variations (e.g., different flavour names and colours). An order specifies how
many copies are required for each variation. All variations share the same footprint, therefore a fixed number of
impressions can be placed on one master board; this capacity is denoted by **$S$** slots.

The objective is to assign every variation to one or more templates together with how many times that template must be
run (**$R_j$**). By grouping variations across several plates we can lower scrap that would otherwise be generated by
using a single plate for everything. The challenge is to find allocation plans that minimise the overall waste for 1, 2,
3 … plates.

## Decision variables

- Allocation matrix **$P_{ij}$**: how many of variation **i** are printed on template **j**.
- Run numbers **$R_j$**: quantity of impressions produced on each template.
- Production metric “Production” representing the total number of sheets processed (**$sum R_j$**).
- Surplus variable quantifying excess board over required output.

## Core constraints (expressed in symbolic form)

1. *Full‑capacity per plate*: for every **j**, the sum of allocated slots equals **$S$**.
2. *Supply coverage*: for each variation **i** the aggregated allocations weighted by the run sizes must meet or exceed
   its demand (**$d[i]$**).
3. *Bounded total production* between a lower bound derived from aggregate demand and an upper estimate; the
   corresponding waste can be expressed as “Surplus = Production × **$S$** – Σ $d[i]$”.
4. *Symmetry breaking*: variations with identical demand must have lexicographically ordered allocation vectors, and
   higher‑demand variations cannot receive proportionally fewer impressions in earlier plates.

The formulation is to minimise “Production”.
