# Template Design for Colour‑Printing Operations

Colour‑printing companies often produce a wide range of products from thin board - cartons for food, magazine inserts,
and the like. Products of the same brand are typically offered in several *variations* (for instance different
flavours), and although the overall shape and size of each variation is identical, the printed text and colour differ
slightly. An order usually contains a mix of quantities for several such variations.

On a *mother sheet* a fixed number of identical slots can be printed. The sheet is etched with a *template* - a thin
aluminium foil that defines which variations, and how many copies of each, will be pressed onto the sheet. The challenge
is twofold:

1. Decide how many distinct templates to produce,
2. Decide, for each template, which variations are allocated to its slots and how many times that template is pressed.

Because all variations have the same size, we know in advance how many slots, denoted by the symbol **S**, fit on a
mother sheet. Let **t** be the number of templates we will produce, **n** the number of distinct variations, and **d[i]
** the required quantity of variation *i* (with *i* ∈ 1 … *n*).

We introduce:

* **p[i,j]** - the number of slots on template *j* that will contain variation *i* (0 ≤ p[i,j] ≤ S).
* **R[j]** - the number of times template *j* is pressed (1 ≤ R[j] ≤ L<sub>upper</sub>).

The model is governed by the following constraints:

| Constraint                                                              | Formulation                                                                       |
|-------------------------------------------------------------------------|-----------------------------------------------------------------------------------|
| **Full utilisation of each template**                                   | ∑<sub>i</sub> p[i,j] = S for every j                                              |
| **Sufficient output of every variation**                                | ∑<sub>j</sub> p[i,j] × R[j] ≥ d[i] for every i                                    |
| **Symmetry breaking (equal demands)**                                   | If d[i] = d[i+1] then lexicographically `p[i,*]` ≤ `p[i+1,*]`                     |
| **Pseudo‑symmetry (non‑decreasing demand → non‑decreasing production)** | If d[i] < d[i+1] then ∑<sub>j</sub> p[i,j] × R[j] ≤ ∑<sub>j</sub> p[i+1,j] × R[j] |

The optimisation goal is to **minimise the total number of presses**:

```
minimise  Σ_j R[j]
```

The search strategy favours smaller values for all variables, treating the decision variables in input order.

By exploring solutions for increasing values of **t** (from 1 upwards) this model yields a family of template plans that
balance the cost of producing templates against the waste generated by unused slots, thereby identifying the most
efficient production scheme for any given set of variations and demand.
