# Optimal Template Planning Problem

This challenge originates from a graphic arts company that manufactures diverse items from thin material, such as
containers for various goods and promotional materials. Goods like these often feature standard designs with multiple
versions, such as different flavors or types, where the core layout remains consistent but minor details or colors vary.
For instance, one series might include two types that share the same size but differ in text or background color. A
common request involves producing specific amounts of several design versions. Since all design versions are uniform in
dimensions, we can predict exactly how many items fit on each large sheet of material, which is determined by the
equipment used. Each large sheet is produced based on a plan, which is a thin metal sheet with patterns for several
variations etched onto it. The task is to determine, first, how many distinct plans to create, and second, which
variations and how many of each to include in each plan.

Let S represent the number of slots per template, t the number of templates, n the number of variations, and d[i] the
demand for each variation i. The problem involves assigning the number of copies for each variation in each template,
denoted by p[i][j], and the number of times each template is used, denoted by R[j]. Each template must utilize exactly S
slots, and the total output for each variation must meet or exceed its demand. Symmetry breaking is applied to handle
identical demands or similar patterns, ensuring a unique solution by ordering the assignments appropriately. Specifically,
if two adjacent variations i and i+1 have identical demands (d[i] == d[i+1]), their allocations across all templates are
lexicographically ordered so that the sequence of p[i][j] is less than or equal to the sequence of p[i+1][j] for j from 1 to t.
Additionally, a pseudo-symmetry constraint specifies that if the demand for variation i is strictly less than the demand
for variation i+1 (d[i] < d[i+1]), then the total printed quantity of variation i across all templates must be less than or
equal to the total printed quantity of variation i+1. The objective is to minimize the total number of template usages,
achieved through an integer search that considers all variables under specific constraints.
