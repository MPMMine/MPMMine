# Assembly Line Routing Problem

A variety of vehicle models are being produced, each with different customizable features. The production line has
stations designed to install these features, but each station has a limited capacity. Furthermore, certain features must
be present together, and number of cars requiring a specific feature in subsequence of the feature-specific length is
limited to prevent overwhelming a station. Therefore, a sequence must be determined to ensure all stations remain within
their capacity limits while fulfilling feature requirements. This problem is known to be computationally hard.
