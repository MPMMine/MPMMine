# Assembly Line Scheduling Problem

A variety of car models are being manufactured, each with unique configurations of optional features. An assembly line
processes these cars, with stations installing features like air conditioning or sunroofs. Each station has a capacity
limit of the total number of cars it can handle in a row of certain size. The goal is to arrange the cars on the
assembly line so that each station's capacity is never exceeded and feature requirements are met. This problem is known
to be computationally hard (Gent, 1999).
